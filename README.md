# Job Market Data Engineering Project

## Contexte métier

Ce projet a pour objectif d'analyser le marché de l'emploi Data en France, en particulier les offres Data Engineer, Data Analyst et BI Analyst.

L'objectif est de construire un pipeline Data Engineering complet permettant de collecter, nettoyer, transformer, modéliser et visualiser les données des offres d'emploi.

## Objectifs du projet

- Collecter des offres d'emploi Data
- Stocker les données brutes dans une zone Bronze
- Nettoyer et standardiser les données dans une zone Silver
- Créer des tables analytiques dans une zone Gold
- Mettre en place des tests de qualité
- Orchestrer le pipeline avec Airflow
- Construire un dashboard Power BI
- Documenter le projet de bout en bout

## Architecture cible

Sources de données  
→ Extraction Python  
→ Zone Bronze  
→ Nettoyage / transformation  
→ Zone Silver  
→ Modélisation dbt / SQL  
→ Zone Gold  
→ Dashboard Power BI
